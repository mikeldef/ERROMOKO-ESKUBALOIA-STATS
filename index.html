Datos y privacidad

Esta web se puede publicar online y usar desde el móvil. En esta versión, los datos se guardan en el navegador del dispositivo.

Importante: publicar la web online no sincroniza automáticamente los partidos entre móviles u ordenadores. Para compartir la misma plantilla e historial entre dispositivos hay que conectar una base de datos segura.

Tras la primera visita con conexión, puede abrirse sin conexión en ese dispositivo. Haz copias de seguridad JSON periódicas.
